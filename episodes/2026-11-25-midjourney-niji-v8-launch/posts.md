## Website article (augaster.com/digest)

### Midjourney's Niji 8 adds a built-in edit model for consistent anime characters

**What happened.** Midjourney has launched Niji 8 (Niji V8), its anime-focused image model, developed in collaboration with Spellbrush. The primary blog post is dated Nov 24, 2026. Midjourney describes it as the fastest and most coherent Niji model yet, with improved spatial reasoning and prompt following. Its X announcement, reported second-hand because the post itself could not be fetched, also cited precision prompting, consistent characters and a dedicated editing model.

**How it works.** The headline feature is the dedicated edit model. It replaces the cref (character reference) feature that Niji 6 had, and it poses characters into different backgrounds while keeping them consistent. You open it with the Quick Edit button at the bottom right of a finished generation, which opens a menu to attach more pictures. The inputs are character sheets and background images, and your prompt refers to them as "image 1" and "image 2". It can also do small touch-ups on a single image, such as adding a hair bun. Secondary reports of Midjourney's docs add that the Edit Model can change images from written instructions, generate from up to four reference images, and edit part of an image or extend the canvas. Those reports attribute this to the main Edit Model in some places and to the Niji V8 editor in others, and the docs were not fetched. Reportedly, the Edit Model is not currently compatible with tile generation or Remix, and Midjourney recommends the raw setting for more precise control.

Output quality depends on input quality, so blurry or pixelated references give worse results. Midjourney's post also recommends the HD feature and demonstrates a multi-object scene and simple multi-panel comic pages from one prompt.

**Availability and price.** Add --niji 8 to a prompt in Discord, or choose "Niji 8" from the Version dropdown in the web interface. The launch announcement did not give pricing changes, benchmark or speed numbers, or API details.

**What it means for small businesses.** If you want recurring illustrated characters, such as a mascot or a cast for social posts, the edit feature is aimed squarely at that. The catch is a change in behavior: unlike Niji 7, Niji 8 does not return the same character for the same prompt wording. It gives a wide variety of results, and longer prompts are less diverse than shorter ones. Consistency is meant to come from the edit feature, and sref and moodboards were also improved.

**Our take.** Treat this as one to test, not to trust blindly. Build clean, sharp character sheets first, try them in a few backgrounds, and judge the results before planning a campaign. Since no pricing changes were announced, check what your current plan covers.
